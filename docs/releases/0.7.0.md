# Hunch SDK 0.7.0 — Safari visual control

Safari gains page screenshots and visual actions through the bundled Hunch extension. Web tools and native Mac tools remain available together, so agents can use the extension for page content and native tools for browser controls or dialogs under the existing session policy.

## Added

- Bind the currently selected Safari tab with `web_open(app="Safari")` without navigating it. An exact URL binds a matching tab or opens it inactive.
- Capture the selected bound tab with `web_screenshot`, and use page-side coordinate clicks, drags, and key actions through `web_act` without posting shared macOS input.
- Request a dedicated background Safari window with `new_window=True`. If Safari changes focus, the extension reports failure and attempts to close the newly created window.
- Carry window, tab, URL, origin, and document identity through Safari requests, map screenshot pixels to page coordinates, and follow supported navigation after actions.

## Fixed

- Allow up to 15 seconds for the bridge response, exceeding the companion's 12-second deadline.
- Distinguish transport failures and timeouts from explicit extension or website permission denials. A timeout reports that an action's outcome may be uncertain.
- Allow screenshot responses up to 16 MiB.

## Validation and compatibility

- 296 Python tests passed locally; PR CI passed on Python 3.11, 3.12, and 3.13, including package building before the version-only preparation.
- Eight Safari JavaScript tests passed. Live extension snapshots and PNG capture were verified.
- A read-only task through the app's agent runtime used Safari web tools and native tools in the same session. The user subsequently confirmed the Google Drive-to-Google Docs creation task worked as intended.
- Includes the signed, notarized Apple Silicon Safari companion. The companion has its own bundle version, independent of the SDK version. Intel Safari companion support is not included.

Safari screenshots require the bound tab to be selected in its window. Page-side synthetic actions may remain unverified on canvas controls. The earlier intermittent connection failure was not conclusively traced to a root cause; this release improves the timeout handling and diagnostics without claiming all connection failures are resolved.

## Distribution

The Python package and MCP registry metadata are set to 0.7.0. Merging this PR to `main` triggers PyPI publication if that version is absent. MCP registry publication and the Homebrew formula update follow the PyPI release. This preparation does not publish a release or update the Hunch desktop app.
