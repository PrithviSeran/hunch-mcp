An agent that runs your Mac, without taking it over.

Hunch lets an LLM operate your real, already-signed-in apps in the background. It reads the accessibility tree and drives native APIs, so it does real work while you keep using your machine.

Benchmark results

We gave three macOS agents the identical model and task prompts on a real, logged-in Mac; only the tool changed. Alongside task success we measured disturbance: how many times the foreground app changed and how far the cursor moved while the agent ran. It's the dimension every VM-based benchmark structurally can't see.

How it works

Every action runs through a single ladder that tries the least disruptive path it can. A screenshot-and-click loop starts at the bottom of this ladder; Hunch starts at the top, which is why it can drive a real Mac without raising an app or moving the pointer.

01OS APIsFiles, clipboard, apps: the direct call, never a click.focus-free
02AppleScriptNative automation for scriptable apps: Mail, Notes, Music, Reminders.focus-free
03Web · Chrome DevToolsDrives a real, logged-in Chrome for things that only live on the web.focus-free
04Accessibility treeReads & acts on any app's UI in the background, even Electron apps like Discord.focus-free
05Vision: screenshot + clickGated last resort, only when no tree exists. This is the only layer that touches the screen.gated

Quickstart

Point any MCP client at it, or import the session object directly in Python. Both are the same engine: one exposed as tools, one as a library.

Install & grant permissions

# PyPI (or: brew install prithviseran/hunch/hunch)
pipx install hunch-sdk
hunch setup      # walk the macOS grants

# then point Claude / Cursor / your agent at:
hunch serve

Or drive it from Python

from hunch import MacSession

mac = MacSession()

# read any app's UI as text, focus-free
tree, _ = mac.snapshot("Discord")

# ...then act on an element in the tree
mac.act("press", ref=...)
