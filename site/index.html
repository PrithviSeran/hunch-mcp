Saved access

Your credentials stay on your Mac.

Hunch stores saved logins, API keys, and tokens in macOS Keychain. It can use them locally when a task requires access, but secret values are never displayed to the AI.

  • Credential values do not appear in the task conversation.
  • Review or delete saved access from Hunch at any time.
  • Keep sending, publishing, and external actions approval-gated.
